# 麻生ハッピー カバネリ海門決戦 島ヒートマップ

slot-eye の台別データ（差枚・回転数）から、麻生ハッピーのカバネリ海門決戦（スマスロ③通路・40台）の翌日の狙い度を出し、島図のヒートマップで表示するサイトです。

公開ページ：https://sat0121.github.io/asabu-kabaneri/

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | サイト本体（Material Design 3。テーマカラーから配色を自動生成） |
| `data.json` | サイトが読むデータ（`tools/build_data.py` が作る） |
| `kabaneri_history.txt` | 蓄積データ。1行1日、`日付: 台=差枚/回転数 ...` |
| `tools/picker.py` | 狙い度の計算と過去日での検証 |
| `tools/build_data.py` | `kabaneri_history.txt` から `data.json` を作る |
| `vendor/` | Material Color Utilities（Apache-2.0）とライセンス |

## データの更新

1. slot-eye「詳細」タブの台別表から、新しい日の行を `kabaneri_history.txt` の末尾に追記する（回転数が空の台は0）。
2. 日別の平均差枚・平均回転数が、slot-eye 画面下の値と一致するか確かめる。
3. `python3 tools/build_data.py` を実行して `data.json` を作り直す。
4. コミットしてpushすると、数分でページに反映される。

ランキングだけ見たいときは `python3 tools/picker.py kabaneri_history.txt`（1〜3台向け）、`--wide`（5台以上向け）。
過去日での成績は `--backtest` で確認できる。

## 狙い度のルール

- 差枚は全日使う。回転数は1万G以上の日をデータなしとして扱う（前日分の加算が疑われるため）。
- **1〜3台向け（v3）**：slot-eye「狙い方別平均（90日）」に当てはめた期待機械割の順位 ＋ 直近7日の平均回転数が少ない順位。
- **5台以上向け（v4）**：上の表の順位 ＋ 0.5×低稼働 ＋ 0.5×連続マイナス日数 − 0.5×連続プラス日数。
- 「隣の台」は実際の島図（同じ列で上下に並ぶ台）で判定する。788と800は隣同士。780と781は通路をはさんだ向かいなので、隣ではない。
