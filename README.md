# 麻生ハッピー カバネリ海門決戦 島ヒートマップ

slot-eye の台別データ（差枚・回転数）から、麻生ハッピーのカバネリ海門決戦（スマスロ③通路・40台）の翌日の狙い度を出し、島図のヒートマップで表示するサイトです。

公開ページ：https://sat0121.github.io/asabu-kabaneri/

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | サイト本体（Material Design 3・スマホ向け。`tools/build_page.py` が作る） |
| `tools/index.template.html` | サイト本体の元ファイル（編集はこちら） |
| `data.json` | サイトが読むデータ（`tools/build_data.py` が作る） |
| `kabaneri_history.txt` | 蓄積データ。1行1日、`日付: 台=差枚/回転数 ...` |
| `tools/picker.py` | 狙い度の計算と過去日での検証 |
| `tools/build_data.py` | `kabaneri_history.txt` から `data.json` を作る |
| `vendor/` | Material Color Utilities（Apache-2.0）、Material Symbols のアイコン（Apache-2.0）とライセンス |

## データの更新

1. slot-eye「詳細」タブの台別表から、新しい日の行を `kabaneri_history.txt` の末尾に追記する（回転数が空の台は0）。
2. 日別の平均差枚・平均回転数が、slot-eye 画面下の値と一致するか確かめる。
3. `python3 tools/build_data.py` を実行して `data.json` を作り直す（ページの見た目を変えたときは `python3 tools/build_page.py` も）。
4. コミットしてpushすると、数分でページに反映される。

ランキングだけ見たいときは `python3 tools/picker.py kabaneri_history.txt`（1〜3台向け）、`--wide`（5台以上向け）。
過去日での成績は `--backtest` で確認できる。

## 狙い度のルール

- **前日の差枚が+3000枚を超えた台は狙わない**（据え置き・上げは狙わない方針）。どちらの狙い度でも候補から外す。
- 差枚は全日使う。回転数は1万G以上の日をデータなしとして扱う（前日分の加算が疑われるため）。
- **1〜3台向け（v3）**：slot-eye「狙い方別平均（90日）」に当てはめた期待機械割の順位 ＋ 直近7日の平均回転数が少ない順位。
- **5台以上向け（v4）**：上の表の順位 ＋ 0.5×低稼働 ＋ 0.5×連続マイナス日数 − 0.5×連続プラス日数。
- 「隣の台」は実際の島図（同じ列で上下に並ぶ台）で判定する。788と800は隣同士。780と781は通路をはさんだ向かいなので、隣ではない。

## クラブイーグル麻生（eagle.html）

同じアプリの2ページ目。画面右上の「ハッピー／イーグル」で切り替える。

- データ：`eagle/eagle_kabaneri.csv`（slot-eye 台別データ。date,machine,diff,games,bb,rb）。現配置は 2026-07-09〜 の46〜68番（23台）。それより前の旧配置（134〜143・162〜173）は学習にだけ使う。
- 更新：CSVに追記 → `python3 tools/build_data_eagle.py`（pandas・scikit-learn が必要）→ `python3 tools/build_page.py` → push
- 狙い度
  - 1〜3台用：勾配ブースティングの予測順位 ＋ 1年表スコア順位 ＋ 0.5×前日差枚1位の隣 ＋ 0.5×前日ボーナス回数の少なさ ＋ 0.5×直近5日に+1500枚超あり ＋ 0.5×直近5日の平均回転数の少なさ
  - 5台以上用：上から機械学習を抜いたもの
  - 前日+3000枚超は除外
- ウォークフォワード検証（上位台の差枚 − その日の全台平均、枚/台）

| | 旧配置 4〜7月 | 7/10〜9/19 | 9/20〜11/21 |
|---|---|---|---|
| 1〜3台用 上位1台 | +381 | +874 | +1258 |
| 1〜3台用 上位3台 | +96 | +727 | +760 |
| 5台以上用 上位5台 | +168 | +377 | +504 |
| ランダム 上位5台 | +23 | −29 | +62 |

- 仮説検証（11/23）：「直近5日+1500超は設定4止まり」→ データでは翌日も良い（加点に採用。減点は全期間で悪化）。「直近の低回転ほど5・6」→ +1500超ありと組み合わせると有効。「祝日はアツい」→ 中央値は祝日+167・平日+35・土日−143。台選びには効かず、画面の「今日の状況」に表示。検証は `eagle/ml/hyp.py`・`ml3.py`・`ml4.py`。
- 「+1500超の日あり」を見る日数を5〜9日で比較（`eagle/ml/ml5.py`、11/23）：日数を広げるほど差が縮む（翌日の全台平均比 あり−なし：5日 +331枚 → 9日 +228枚）。総合で5日が最良なので5日のまま。
- 効かなかったもの：直近7日の低稼働（麻生ハッピーの v3 の柱）はこの店では逆効果。前日差枚の少なさ・台クセも負け。
- 島は 46〜56 と 57〜68 の2つ（56と57は隣ではない）。2列で表示し、「隣」は同じ島の番号の前後で判定。手前・奥の向きは未確認。
- 検証スクリプト：`eagle/ml/`（bt.py＝表ベース、ml.py／ml2.py＝機械学習と組み合わせ）
